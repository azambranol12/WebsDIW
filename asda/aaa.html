1. Content-box vs border-box

El box model decide si el width incluye solo el contenido o tambien el padding y el border.

content-box

width: 260px

Ancho real = content width + padding izquierdo/derecho + border izquierdo/derecho. Si hay width: 260px; padding: 24px; border: 6px, ocupa 320px.

border-box

width: 260px

Ancho real = el width indicado. El contenido se reduce para dejar sitio al padding y al border. Con los mismos valores, ocupa 260px.

Importante de examen

Por defecto, la mayoria de elementos HTML usan box-sizing: content-box. Muchos controles de formulario del navegador se renderizan internamente de forma especial, pero no conviene depender de eso. En proyectos reales se suele poner: 

*,
*::before,
*::after {
  box-sizing: border-box;
}

2. Como calcular medidas, padding, border y margin

Si es content-box

width: 50% se calcula sobre el ancho del contenedor padre.

Luego se suma padding + border. El margin tambien ocupa espacio exterior, pero no forma parte del width de la caja.

Total = width + padding L/R + border L/R + margin L/R

Si es border-box

width: 50% sigue calculandose sobre el padre, pero ese 50% ya incluye contenido + padding + border.

Total = width + margin L/R

width: 50%

Esta caja hija mide el 50% del area de contenido del padre. El padding del padre reduce el espacio interior disponible donde vive la hija.

flex-grow

Reparte el espacio sobrante. Si un item tiene flex-grow: 1, puede crecer. Si otro tiene flex-grow: 2, recibe el doble de espacio sobrante.

flex-shrink

Decide cuanto se encoge un item cuando no cabe. Por defecto es 1. Si pones flex-shrink: 0, ese elemento intenta no encogerse.

4. Float, inline-block y cuando usarlos

Float

float: right

float se uso mucho para layouts antiguos, pero hoy se usa sobre todo para que texto rodee una imagen/caja. Para maquetar columnas, mejor flex o grid.

Si un contenedor tiene hijos flotados, puede necesitar clear o clearfix para no colapsar.

Inline-block

inline-block en linea pero con medidas

inline-block permite que elementos esten en linea y acepten width, height, padding y margin vertical. Es util para chips, botones o etiquetas sencillas.

5. Display flow-root

display: flow-root crea un nuevo contexto de formato de bloque. Dicho en cristiano: hace que el contenedor encierre bien a sus hijos flotados y evita algunos problemas raros de margenes.

Sin flow-root

float

Esta caja tiene un hijo flotado. Si solo hubiera elementos flotados dentro, el contenedor podria quedarse sin altura porque los floats salen parcialmente del flujo normal.

Con flow-root

float

Con display: flow-root, el contenedor crea su propio contexto y abraza el contenido flotado. Es una alternativa limpia al clearfix antiguo.

Cuando usarlo

Usalo cuando trabajes con float y quieras que el padre calcule bien su altura, o cuando necesites aislar el flujo interno de una caja. No sustituye a flex ni grid para maquetar layouts modernos.

6. Position: static, relative, absolute, fixed y sticky

absolute
caja normal

static: valor por defecto. El elemento sigue el flujo normal.

relative: sigue ocupando su sitio, pero puedes moverlo con top/right/bottom/left.

absolute: sale del flujo y se posiciona respecto al ancestro posicionado mas cercano.

fixed: se posiciona respecto a la ventana. Se queda fijo al hacer scroll.

sticky: empieza normal y se queda pegado cuando llega a un limite, por ejemplo top: 0.

Truco clave: si quieres colocar algo absoluto dentro de una tarjeta, pon position: relative en la tarjeta y position: absolute en el hijo.

Elementos que van en linea por defecto: span, a, label, strong, em, input, select, textarea y button.

Box-sizing por defecto en formularios

La propiedad CSS inicial de casi todos los elementos es box-sizing: content-box, pero los navegadores suelen aplicar estilos internos distintos a algunos controles.

Elemento Box-sizing habitual por defecto
input type="text", email, password, number, date content-box en la teoria CSS inicial, aunque puede variar por navegador.
button, select border-box habitualmente por estilos del navegador.
input type="button", submit, reset, checkbox, radio, color, search border-box habitualmente por estilos del navegador.
textarea content-box habitualmente si no lo cambias.

Para examen: si te preguntan por CSS puro, el valor inicial es content-box. Si te preguntan por controles concretos del navegador, recuerda que button, select y varios input especiales suelen venir en border-box.

8. Media queries

Las media queries aplican CSS solo si se cumple una condicion. Lo normal es hacer diseno responsive segun el ancho de pantalla.

1 columna en movil
2 columnas en tablet
3 columnas en escritorio
.responsive-demo {
  display: grid;
  grid-template-columns: 1fr;
}

@media (min-width: 700px) {
  .responsive-demo {
    grid-template-columns: repeat(2, 1fr);
  }
}

@media (min-width: 1000px) {
  .responsive-demo {
    grid-template-columns: repeat(3, 1fr);
  }
}

min-width suele usarse en mobile first: primero estilos de movil, luego mejoras para pantallas mas grandes. max-width se usa cuando partes de escritorio y corriges hacia abajo.

9. Chuleta rapida para el examen

Flex container

display: flex, flex-direction, justify-content, align-items, gap, flex-wrap.

Flex item

flex-grow crece, flex-shrink encoge, flex-basis tamano inicial, align-self alinea un item.

Porcentajes

El porcentaje de width se calcula segun el ancho disponible del padre. Padding horizontal en % tambien se basa en el ancho del contenedor.

Margins

El margin es espacio exterior. Margenes verticales entre bloques pueden colapsar. En flex/grid no colapsan igual.

Absolute

Sale del flujo. Busca el primer padre con position distinto de static. Si no existe, usa la pagina/viewport.

Float

Usalo para rodear con texto, no como layout principal moderno. Recuerda clear.
